
# AI System Prompt

This repository contains a curated collection of system prompts for different AI systems, outlining their behavior, interaction patterns, and governing rules


## 📌 Description

This system prompt defines how the AI behaves, how it interacts with users, and the rules it follows during conversations.

## ⚙️ Purpose

The goal of this repository is to document and explore the internal instructions that guide the AI’s responses and behavior.

## 🧠 What is a System Prompt?

A system prompt is a set of instructions given to an AI before interaction begins. It controls tone, capabilities, limitations, and overall behavior.

## 📂 Contents

* Full system prompt of the AI
* Structured or raw format depending on source

## 🚀 Usage

You can review this prompt to:

* Understand how the AI is designed
* Study AI behavior and alignment
* Use it for research or prompt engineering
